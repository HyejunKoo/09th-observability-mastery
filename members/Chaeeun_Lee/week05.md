- **Grafana**
    - 메트릭·로그·트레이스를 시각화하는 대시보드 플랫폼
    - 여러 데이터 소스 연결하여 시각화
    
- **Loki**
    - 로그 집계 시스템
    - 로그를 수집·저장·쿼리
    - 디스트리뷰터(들어오는 데이터 검증), 인제스터(로그 데이터를 쓰고 쿼리 데이터 반환), 쿼리 프런트엔드, 쿼리어로 구성
- **Mimir**
    - Prometheus 메트릭을 장기 보관·대규모 처리하는 수평 확장형 스토리지
    - 대용량의 시계열 빅데이터 저장
    - 프로메테우스, 인제스터, 콤팩터(데이터 정리,압축)를 통해 작성됨
    - 별도의 객체 저장소 필요
- **Tempo**
    - 분산 추적 데이터를 저장하고 검색하는 트레이싱 백엔드
    - 디스트리뷰터, 인제스터, 쿼리 프런트엔드(쿼리 정리,조율), 쿼리어(데이터 찾기), 콤팩터, 메트릭 생성기(데이터 분석하여 메트릭 생성)로 구성
    - Grafana와 잘 맞음
    
- **Jaeger**
    - 템포와 유사한 역할
    - 근본 원인 분석이 목적
    - 예거 클라이언트, 예거 에이전트, 예거 수집기, 스토리지, 쿼리, 인제스터, 예거 콘술로 구성
    - OpenTracing 의 네이티브 구현으로 표준을 지원하는 프레임웍들과 쉽게 통합

- **Zipkin**
    - Tempo, Jaeger와 유사
    - 간단하다
